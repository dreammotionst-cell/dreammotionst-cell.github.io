# dreammotionst-cell.github.io

Trang web công khai của Dream Motion Games (GitHub Pages). Mỗi game một thư mục.

- Ocean Chomp — hỗ trợ: https://dreammotionst-cell.github.io/ocean-chomp/support/
- Ocean Chomp — quyền riêng tư: https://dreammotionst-cell.github.io/ocean-chomp/privacy/

Không sửa tay các trang: chúng được sinh từ kho `ocean-chomp`
(`python3 tools/sitegen.py --pages <thư mục kho này>`), chữ khớp với chữ trong game, đủ 10 tiếng.
